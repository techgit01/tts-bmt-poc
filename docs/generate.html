🎙️ Supertonic 한국어 음성 생성

목소리(F1~F5 / M1~M5) · 속도(1.0x) · 텍스트(최대 500자)로 직접 합성해 보세요. 이 페이지는 정적(GitHub Pages)이라 합성 자체는 Colab의 생성기에서 실행됩니다 — 아래 3단계로 연결하면 이 화면 안에서 바로 사용할 수 있습니다.

🔊 목소리 안내 — Supertonic 내장 10종 화자입니다. F1~F5 = 여성 5종, M1~M5 = 남성 5종. 각 번호는 서로 다른 화자(목소리)이며 공식 캐릭터 설명(나이·톤)은 제공되지 않습니다 → 같은 문장을 여러 목소리로 생성해 비교하고 마음에 드는 걸 고르세요.

1 · 생성기 실행 (Colab)

1
아래 노트북을 열고 “🎙️ 인터랙티브 생성기” 셀을 실행합니다 (최초 1회 ~400MB 모델 다운로드).
2
실행하면 출력에 https://xxxx.gradio.live 형태의 공개 URL이 뜹니다.
3
셀이 출력하는 “자동 연결 링크”(generate.html?u=…)를 클릭하면 이 화면에 생성기가 자동으로 연결됩니다. (또는 gradio.live URL을 아래에 직접 붙여넣어도 됩니다.)

2 · 생성기 연결

붙여넣은 URL은 이 브라우저에만 저장됩니다(localStorage).

아직 연결된 생성기가 없습니다. 위 단계로 Colab 생성기를 실행하고 URL을 연결하세요.

⚠️ Gradio gradio.live URL은 Colab 세션이 살아있는 동안만 유효합니다(세션마다 바뀜). 상시 운영하려면 Hugging Face Spaces 등 영구 호스팅에 같은 Gradio 앱을 올리면 됩니다.
