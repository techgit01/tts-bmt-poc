이 페이지는 무엇인가요?

카드사 FDS(부정거래) 음성 상담을 가정한 한국어 5문장을, 중국 개발 엔진을 제외한 상업용 무료 오픈소스 TTS 4종으로 합성해 같은 조건에서 비교합니다. 각 카드에서 문장별 합성 오디오를 직접 재생하고 속도 지표를 볼 수 있습니다.

모드 — 꼭 확인하세요

  • 실측 실제 TTS 엔진이 합성한 진짜 음성입니다.
  • 시뮬레이션 엔진 미연결 시 파이프라인 검증용으로 만든 합성 사인파(“웅—” 톤)입니다. 실제 음질이 아닙니다.

현재 Supertonic · kr-custom-tts · SCE-TTS 는 실측, piper-plus 만 시뮬레이션입니다 (호환되는 한국어 음성모델 부재 — 유일한 한국어 piper 모델이 piper-plus 비호환 phonemizer를 사용).

지표

  • 평균 RTF = 합성시간 ÷ 오디오길이. 낮을수록 빠름 (0.1 = 1초 오디오를 0.1초에 생성). 실측 엔진은 시뮬레이션보다 RTF가 큽니다(실제 추론).
  • 문자/초 = 초당 처리한 한국어 글자 수. 높을수록 빠름.

음성이 “웅—” 소리만 나나요?

그 카드가 시뮬레이션 이기 때문입니다. 실측 태그가 붙은 카드(▶)를 재생하면 실제 한국어 음성이 들립니다.

내 문장으로 직접 생성해보기

상단 🎙️ Supertonic으로 직접 생성해보기 버튼 → 저장소에 포함된 생성기 화면 (generate.html)에서 목소리(F1~F5/M1~M5) · 속도(1.0x) · 텍스트(최대 500자) · 예문 으로 합성합니다. 정적 페이지라 합성은 Colab 생성기(Gradio)를 백엔드로 연결해 실행됩니다(URL 붙여넣기).

학습 데이터셋

각 카드의 데모 음성이 어떤 데이터로 학습됐는지(카드의 데이터셋 줄에도 표시):

  • Supertonic — Supertone 자체 데이터(비공개), 다국어. 데모는 내장 보이스 F1.
  • kr-custom-tts / SCE-TTS — KSS(Korean Single Speaker, 여성 1인 ~12h, 12,853발화). ESPnet 사전학습(JETS / VITS).
  • piper-plus — 현재 시뮬레이션이라 학습 데이터 없음(합성 톤).

⚠️ KSS 는 CC BY-NC-SA 4.0 — 비상업용입니다. kr-custom·SCE 데모 음성은 데모 용도이며 상업 배포 불가. 상업적으로 쓰려면 본인/상업 가능 데이터로 파인튜닝하세요(아래 참고). KSS

엔진별 파인튜닝(커스텀 음성)

본인/브랜드 음성으로 바꾸려면 각 엔진을 파인튜닝합니다. 공통 준비물: 음성 wav + 전사 텍스트(보통 수십 분~수 시간 분량)와 GPU. 처음부터 학습보다 사전학습 체크포인트에서 이어 학습(파인튜닝)이 빠릅니다.

  • Supertonic — 그래디언트 학습 대신 Voice Builder(음성 클로닝) 로 참조 음성에서 커스텀 보이스 스타일 생성 → get_voice_style() 에 지정. 가이드
  • piper-plus — 베이스 음성모델(.onnx/ckpt)에서 데이터셋으로 resume 학습, 또는 Speaker Encoder 기반 음성 클로닝. 가이드
  • kr-custom-tts (ESPnet) — ESPnet2 TTS 레시피에서 사전학습 모델을 --init_param 초기값으로 두고 본인 데이터로 파인튜닝. 가이드
  • SCE-TTS — 원 가이드(Tacotron2 자가학습) 또는 데모와 동일한 ESPnet VITS 파인튜닝. 가이드

학습 산출물은 tts-bmt run --model <engine>=<경로> 로 연결하면 해당 카드가 본인 음성으로 바뀝니다. 단계별 셀은 Colab 노트북의 (선택) 학습 섹션 참고.
